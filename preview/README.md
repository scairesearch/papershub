# Preview only

Not the product. `main` at `5cae7dd` is the Phoenix workspace and stays the line to build on.

This branch is the browser sketch of the catalog loop, the claim desk, and works after the 29 June 2026 snapshot. It is here so that sketch is not lost and does not land on `main`.

Drawbacks:

- It is not the Phoenix app. Search, the neighborhood graph, and the source adapters are not in these files.
- The pipeline runs a written sample. It does not read the OpenAlex snapshot.
- Papers dated after the snapshot are examples, not a live cursor.
- Select is a keyword check, not the shard.
- Accepts and pins stay in the browser.
- The concept layout is fixed. A claim still does not enter the graph until it is accepted.
